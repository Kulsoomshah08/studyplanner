# 📚 StudyPlanner AI

## About
StudyPlanner AI is a web app that helps students manage study tasks, track progress, and get instant help from an AI assistant. It is designed to make studying more organized and productive.

## 🌐 Live Demo
Live App:! [live app](https://ai-study-planner-web-0ff0.bolt.host/#home)

## ✨ Features
- Add and manage study tasks
- Track task progress
- Dashboard with task statistics
- AI Study Assistant
- Responsive design

## 🤖 AI Feature
The AI Assistant answers study-related questions and explains topics in simple language.

System Prompt:
> "You are a helpful study assistant. Explain concepts clearly using simple language and examples."

## 🛠 Built With
- React.js
- Vite
- Tailwind CSS
- Firebase
- OpenAI API
- GitHub
- Vercel/Netlify
